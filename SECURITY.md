# Security Policy

## Supported versions

The latest released version on the `main` branch receives security fixes.

| Version | Supported |
| ------- | --------- |
| 0.1.x   | ✅        |

## Reporting a vulnerability

Please **do not** open a public issue for security vulnerabilities.

Instead, email **[support@viprasol.com](mailto:support@viprasol.com)** with:

- a description of the issue and its impact,
- steps to reproduce, and
- any suggested remediation.

We aim to acknowledge reports within 72 hours and will keep you updated on
remediation progress. Responsible disclosure is greatly appreciated.
